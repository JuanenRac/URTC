VARIANT: BASIC - no MCU. Same role as BOM_EXPANSION_BASIC_TMC2209.TXT,
         higher-power driver for tools whose motor draws more than the
         TMC2209's own 2A/coil ceiling.
DRIVER: TMC5160A - unlike TMC2209, this driver has NO integrated power
        MOSFETs; it drives external gate-level transistors instead (per
        Analog Devices' own official datasheet, TMC5160A_datasheet_rev1.17:
        "Eight MOSFETs are selected for the desired current, voltage and
        package type. Two sense resistors set the motor coil current.").
        This is the real, verified reason this variant's BOM is
        substantially longer than the TMC2209 variant's - not an
        oversight, the driver genuinely needs this support circuitry to
        function at all.
SOURCE: Same provisional-BOM caveat as BOM_EXPANSION_BASIC_TMC2209.TXT -
        no schematic exists yet to source real reference designators
        from. MOSFET part number below is a reasonable placeholder for a
        10V-gate-drive, low-RDSon N-channel part in this power class -
        confirm against the actual target coil current once that's
        specified, this isn't a part number pulled from an existing
        design the way the main board's own BOM.TXT entries are.

2. LOCAL POWER
--------------------------------------------------------------------------------
RefDes      Qty        Value / Model       Package         Notes / Description
--------------------------------------------------------------------------------
Same as BOM_EXPANSION_BASIC_TMC2209.TXT - logic power drawn from the
main board's own expansion connector, no local regulator populated.
Motor supply (VS/VM for Q1-Q8's own bridge) is a separate consideration
from logic power - typically the same higher-voltage rail already
feeding the main board's own onboard driver, routed to this board
alongside the link connector's other signals; exact voltage/current
budget TBD alongside the rest of this variant's power design.
