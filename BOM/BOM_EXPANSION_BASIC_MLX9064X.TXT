VARIANT: BASIC, sensor-only - no stepper driver, no MCU, and no sensor
         chip itself mounted directly on this board. Carries a 4-pin
         connector for whichever MLX9064x-family sensor module is
         plugged into it (MLX90640, MLX90641, or MLX90642 - see
         EEPROM.TXT section 6 and CANBUS.TXT's own 0x1A6/0x1A7 for how
         which variant is actually installed gets configured), plus
         decoupling, talking directly to the main URTC board's own
         STM32F303CC over the existing expansion connector's bit-banged
         I2C bus (same physical bus an Advanced board's own slave chip
         uses, just no slave chip here - see
         melexis_mlx90641/firmware_mlx90641_transport.c). Fits doc #13
         (PCB Advanced Inspection)'s own thermal-imaging path when a
         tool needs only this sensor and nothing else an Advanced board
         also carries (the local PWM, the ADS1115).
SENSOR: All 3 MLX9064x family members (MLX90640 32x24, MLX90641 16x12,
        MLX90642 32x24 with onboard temperature calculation) share the
        same industry-standard 4-lead TO39 package and the same 4
        signals (VDD, GND, SDA, SCL) - confirmed against each sensor's
        own short-form datasheet - so this board's own connector footprint
        doesn't change between which of the 3 is actually populated on
        the sensor module plugged into it.
SOURCE: Component selection below is a first-pass BOM for a board that
        hasn't been laid out in Eagle yet - unlike the main URTC board's
        own BOM.TXT (sourced from an actual exported schematic/netlist),
        treat reference designators here as provisional until a real
        schematic exists to assign them from.
