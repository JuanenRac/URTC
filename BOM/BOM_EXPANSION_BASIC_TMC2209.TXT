VARIANT: BASIC - no MCU. Carries the stepper driver and the tool-facing
         connectors only; STEP/DIR/EN come directly from the main URTC
         board's own STM32F303CC over the existing expansion connector.
         Fits any of the 15 new tools that don't need local PWM or the
         2 local I2C sensor chips (see docs/PINOUT_SLAVE.txt for the
         full basic-vs-advanced breakdown).
DRIVER: TMC2209 - integrated power MOSFETs (up to 2A RMS per coil per
        the driver's own datasheet), no external power stage needed.
SOURCE: Component selection below is a first-pass BOM for a board that
        hasn't been laid out in Eagle yet - unlike the main URTC board's
        own BOM.TXT (sourced from an actual exported schematic/netlist),
        treat reference designators here as provisional until a real
        schematic exists to assign them from.

2. LOCAL POWER
--------------------------------------------------------------------------------
RefDes      Qty        Value / Model       Package         Notes / Description
--------------------------------------------------------------------------------
Note: this board draws its own logic power from the main board's own
expansion connector rather than regulating its own - the connector
already carries a +3.3V rail from the main board's own AP2112K LDO
(main board's own BOM.TXT section 1), and a basic-variant board has no
load beyond the driver's own logic pins, well within that rail's
existing budget. No local regulator populated.
