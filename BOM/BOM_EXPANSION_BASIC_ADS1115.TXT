VARIANT: BASIC, sensor-only - no stepper driver, no MCU. Carries the
         ADS1115 16-bit ADC and its own minimal support components
         only; the chip talks directly to the main URTC board's own
         STM32F303CC over the existing expansion connector's bit-banged
         I2C bus (same physical bus an Advanced board's own slave chip
         uses, just no slave chip here - see firmware_ads1115.c). Fits
         doc #7 (Functional Testing Head)'s own "advanced reading" path
         when a tool needs only this chip and nothing else an Advanced
         board also carries (the local PWM, the thermal sensor).
CHIP: ADS1115 - 16-bit I2C ADC, 4 single-ended or 2 differential
      inputs, internal reference and oscillator - no external
      crystal or reference needed.
SOURCE: Component selection below is a first-pass BOM for a board that
        hasn't been laid out in Eagle yet - unlike the main URTC board's
        own BOM.TXT (sourced from an actual exported schematic/netlist),
        treat reference designators here as provisional until a real
        schematic exists to assign them from. Support-component values
        verified against Texas Instruments' own ADS1115 datasheet
        (SBAS444) rather than assumed - see the notes column below for
        which requirement each part traces back to.

Note: no pull-up resistors populated on SCL/SDA here - the main URTC
board's own expansion connector already carries 4.7k pull-ups on both
lines (R48/R44, see docs/PINOUT_CONNECTORS.TXT), since this is the same
physical bus an Advanced board's own slave chip already uses. Adding a
second pair here would only needlessly lower the bus's own effective
pull-up resistance. ALERT/RDY is left unconnected (NC) - this project's
own firmware polls the conversion result rather than using
interrupt-driven or comparator-triggered reads, so the open-drain
ALERT/RDY pin's own pull-up (which TI's datasheet does call out as
needed if that pin is actually used) isn't needed on a board that
never connects it to anything.

Only 3 components support the ADC chip itself, not necessarily 4 -
verified against the actual datasheet requirement rather than assumed;
see the note above for what would add a 4th (an ALERT/RDY interrupt
line) if a future design ever needs it.
