VARIANT: ADVANCED - adds the STM32F303CBT6 slave MCU plus the 2 local
         I2C sensor chips (ADS1115, MLX90640) and local PWM generation
         on top of everything BOM_EXPANSION_BASIC_TMC2209.TXT already
         has. Required for any of the 15 new tools needing local PWM
         (doc #4/#14/#15) or the 2 sensor chips (doc #7/#13) - see
         docs/PINOUT_SLAVE.txt for the full breakdown of which signals
         this variant carries that the basic variant doesn't.
DRIVER: TMC2209 - same driver section as BOM_EXPANSION_BASIC_TMC2209.TXT,

future firmware revision changes this assumption.

4. LOCAL PWM CONNECTOR SUPPORT
--------------------------------------------------------------------------------
RefDes      Qty        Value / Model       Package         Notes / Description
--------------------------------------------------------------------------------
No additional passives required beyond the tool-facing connector itself
(section 6 below) - TIM1's own 4 PWM channels drive directly from the
MCU's own GPIO pins (docs/PINOUT_SLAVE.txt Block 4), any
buffering/level-shifting needed is tool-specific and not part of this
board's own base BOM.

--------------------------------------------------------------------------------
5. LINK BUS (I2C1) SUPPORT
--------------------------------------------------------------------------------
RefDes      Qty        Value / Model       Package         Notes / Description
--------------------------------------------------------------------------------
Note: I2C1's own pull-ups are NOT populated on this board - this bus is
shared with the main board's own EXP_I2C2 (same physical wire through
the link connector), and pull-ups for it already exist on the main
board's own side (wherever ExpansionI2C_* assumes them today). Adding a
second set here would double up the effective pull-up strength on a
shared bus, which isn't what's wanted.
